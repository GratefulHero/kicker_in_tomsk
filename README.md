# kicker_in_tomsk
Это первый мой лендинг, созданный с нуля.
Сайт сделан для привлечения новичков в настольный футбол (кикер).
Основная цель: познакомить с видом спорта и собрать аудиторию в группу ВК.
Сайт содержит header, hero-блок, три блока с информацией, форму, подвал.
Использованные технологии: HTML, CSS, SCSS (Gulp), JS.
Использованные библиотеки: Bootstrap, Animate.css, подключение шрифтов из Google Fonts.
