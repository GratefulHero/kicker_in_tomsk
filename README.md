# kicker_in_tomsk
Это первый мой лендинг, созданный с нуля.<br>
Сайт сделан для привлечения новичков в настольный футбол (кикер).<br>
Основная цель: познакомить с видом спорта и собрать аудиторию в группу ВК.<br>
Сайт содержит header, hero-блок, три блока с информацией, форму, подвал.<br>
Использованные технологии: HTML, CSS, SCSS (Gulp), JS.<br>
Использованные библиотеки: Bootstrap, Animate.css, подключение шрифтов из Google Fonts.<br>
